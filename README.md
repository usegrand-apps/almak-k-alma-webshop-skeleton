# Almakék — alma webshop — UI skeleton

Live skeleton: https://usegrand-apps.github.io/almak-k-alma-webshop-skeleton/

Planned with [UIPrompt](http://127.0.0.1:3000/?utm_source=github_readme&utm_medium=skeleton): a visual canvas that turns UI plans into a structured brief for AI coding agents (Claude Code, Cursor, Codex…).

## Files

The skeleton lives on the [`gh-pages` branch](https://github.com/usegrand-apps/almak-k-alma-webshop-skeleton/tree/gh-pages), which GitHub Pages serves:

- `index.html`: the page, its frames stacked in flow order, served by GitHub Pages
- `skeleton.json`: screens, sections and connections as data
- `brief.md`: the full brief to hand to your AI coding agent

Republish from UIPrompt to update the site.
